# GREEN-API Чат

Минимальный web-чат в стиле мессенджера (тёмная тема) с текстовыми сообщениями через HTTP API [GREEN-API](https://green-api.com). React + Vite.

[English README](./README.md)

## Возможности

- Вход по учётным данным собственного инстанса GREEN-API (`idInstance`, `apiTokenInstance`, опционально `apiUrl`)
- Создание чата по номеру телефона (`CheckWhatsapp` с fallback на `<phone>@c.us`)
- Отправка текста методом `SendMessage`
- Получение сообщений поллингом `ReceiveNotification` (long poll, ~5 с) с подтверждением через `DeleteNotification`
- Счётчики непрочитанных, поиск по чатам, входящие от неизвестных chatId автоматически создают новый чат
- Форматирование сообщений: `*жирный*` / `**жирный**`, `> цитаты`, кликабельные ссылки (включая `[текст](url)`)
- Только текст — без файлов, групп и звонков

## Требования

- Node.js 18+ и npm
- Инстанс GREEN-API в [console.green-api.com](https://console.green-api.com)

## Запуск

```bash
npm install
npm run dev
```

Откройте URL, который выведет Vite (по умолчанию `http://127.0.0.1:5173`).

Продакшен-сборка:

```bash
npm run build
npm run preview
```

## Настройка

На экране входа введите:

| Поле | Обязательно | Описание |
| --- | --- | --- |
| `idInstance` | да | ID инстанса из личного кабинета GREEN-API |
| `apiTokenInstance` | да | Токен инстанса |
| `apiUrl` | нет | По умолчанию `https://<первые 4 цифры idInstance>.api.green-api.com` |

Учётные данные хранятся только в `localStorage` браузера — в исходном коде ничего не захардкожено.

## Требования к инстансу GREEN-API

- Инстанс должен быть **авторизован** (отсканируйте QR-код в кабинете), иначе исходящие сообщения стоят в очереди до 24 ч. Интерфейс показывает предупреждение при статусе `notAuthorized`.
- Для получения через HTTP API включите в настройках инстанса `incomingWebhook` / `outgoingWebhook` / `stateWebhook` и оставьте `webhookUrl` пустым.

## Сценарий проверки

1. Открыть приложение, ввести `idInstance` + `apiTokenInstance`, нажать **Войти в чат**.
2. Нажать **+**, ввести номер получателя, нажать **Создать чат**.
3. Выбрать чат, написать текст, нажать **Enter** или ➤.
4. Ответить с телефона получателя.
5. Ответ появится автоматически (поллинг каждые ~5 с). Сообщения от неизвестных chatId создают новый чат сверху списка.

Для полной проверки нужен **второй номер телефона** — отправка самому себе не вернётся входящим сообщением.

```
  App.jsx                     Каркас приложения: авторизация, вёрстка, хуки

  hooks/useChats.js           Состояние чатов, алиасы, отправка, персист

  components/ChatList.jsx     Сайдбар: поиск, список чатов, бейджи, футер
  components/ChatWindow.jsx   Сообщения, рендер форматирования, композер
  components/NewChatModal.jsx Диалог создания чата
  utils.js                    Цвета аватаров, формат времени/даты
  styles.css                  Тёмная тема мессенджера
```
